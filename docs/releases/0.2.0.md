# QSAutomate 0.2.0 Release Notes

**Release Date:** February 5, 2026

## Overview

This release modernizes QSAutomate with a complete packaging overhaul using `uv` and significant Prefect workflow improvements including caching, retries with exponential backoff, and centralized configuration.

---

## Highlights

### Modern Python Packaging with UV

- **`uv` as the package manager** - Faster, more reliable dependency resolution
- **`pyproject.toml` as single source of truth** - Removed `requirements.txt`
- **One-command installation** - `uv sync` handles everything
- **Simplified execution** - All commands use `uv run` prefix

### Prefect Best Practices

- **Centralized task configuration** - Shared retry, caching, and timeout settings
- **Exponential backoff with jitter** - Smart retry strategies for API calls
- **24-hour input-based caching** - Skip redundant data downloads
- **5-minute trading timeout** - Prevent hung broker connections
- **Prefect-native logging** - `get_run_logger()` for better observability
- **Simplified flow orchestration** - Direct task calls instead of verbose submit/wait/result

## New Features

### UV Packaging System

| Feature | Description |
|---------|-------------|
| `uv sync` | Single command to create venv, install deps, and install project in editable mode |
| `uv run <cmd>` | Run any command in the project environment without activation |
| `pyproject.toml` | Modern PEP 621 compliant project configuration |
| Hatchling backend | Supports git dependencies with `allow-direct-references` |

### Simplified Flow Orchestration

Before (verbose):
```python
prices_f = download_prices_fmp.submit(start_date, run_date)
prices_f.wait()
prices_f.result()
bundle_f = build_zipline_bundle.submit(bundle_name, wait_for=[prices_f])
bundle_f.wait()
bundle_f.result()
```

After (clean):
```python
prices_future = download_prices_fmp.submit(start_date, run_date)
fundamentals_future = download_fundamentals_fmp.submit(start_date, run_date)
wait([prices_future, fundamentals_future])

build_datalake_fmp()
build_zipline_bundle(bundle_name)
perf = run_zipline_backtest(config, backtest_fcn)
execute_trades(perf, strategy_reference, client_id=client_id, host=host)
```

## Breaking Changes

### Python Version

- **Now requires Python 3.11** (previously 3.12+)
- Changed due to numpy/pandas_datareader compatibility issues with Python 3.12+

### Removed Files

| File | Reason |
|------|--------|
| `requirements.txt` | Replaced by `pyproject.toml` |
| `justfile` | Replaced by `uv run` commands in README |
| `qsautomate/strategies/multi_parameter.py` | Unused |
| `qsautomate/strategies/multi_strategy.py` | Unused |
| `.vscode/` | IDE-specific, removed from repo |

### Installation Changes

**Old:**
```bash
pip install -r requirements.txt
```

**New:**
```bash
uv sync
```

### Running Commands

**Old:**
```bash
python qsautomate/strategies/qsmomentum.py
mlflow server --port 8031 ...
prefect server start
```

**New:**
```bash
uv run python qsautomate/strategies/qsmomentum.py
uv run mlflow server --port 8031 ...
uv run prefect server start
```

## Upgrade Guide

1. Install uv if not already installed:
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. Pull the latest changes:
   ```bash
   git pull origin main
   ```

3. Install dependencies:
   ```bash
   uv sync
   ```

4. Enable Prefect caching:
   ```bash
   uv run prefect config set PREFECT_RESULTS_PERSIST_BY_DEFAULT=true
   ```

5. Update any scripts to use `uv run` prefix
